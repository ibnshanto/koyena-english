# Koyena English — English Grammar Practice Platform

## What this is
Two visible practice systems:
1. **Grammar Engine** — 20 full topics, each with a complete lesson (intro, rule sections, common mistakes, decision tree, quick-check questions) and a 50-exam practice bank (1,000 questions per topic).
2. **Think & Answer** — 50 open-ended production exam sets (simulated AI analysis).

IELTS Practice remains hidden from navigation for now — code exists but isn't linked in the nav yet, pending the AI-graded Writing/Speaking build-out.

## The 20 grammar topics
Sentence Structure, Nouns, Pronouns, Articles, Subject-Verb Agreement, Present Tenses, Past Tenses, Future Forms, Verb Patterns (Gerunds & Infinitives), Modal Verbs, Adjectives, Adverbs, Prepositions, Conjunctions & Linking Words, Relative Clauses, Conditionals, Passive Voice, Reported Speech, Word Formation, Punctuation & Capitalization.

(Nouns & Pronouns and Adjectives & Adverbs were originally combined topics, later split into 4 separate topics for clearer, more focused lessons.)

## How to run it locally
1. Install Node.js (nodejs.org)
2. Terminal in this folder → `npm install` → `npm run dev`
3. Open the link shown (usually http://localhost:5173)

## How to deploy it live (free)
1. GitHub account → new repository → upload files
2. Vercel account (sign in with GitHub) → Import Project → Deploy
